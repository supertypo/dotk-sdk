@dotk/sdk in the browser

This page resolves .k names on Kaspa, live, from a browser. Save it, open it, and press a button. Every snippet below is the code that the button runs.

The page loads the published package from esm.sh, so it needs an internet connection. It reads and never spends. Nothing here needs a wallet or a key.

Loading the package from esm.sh.

Every snippet runs with dotk, a client of the registry you picked, and with name, address and input from the fields above. The package's own exports are in scope under sdk, and subnames is one of them.

To run a snippet against a build of this repository, serve the repository over HTTP and point the import map at ../dist/index.js. A browser refuses a relative module import from a file: page.

The package is @dotk/sdk on npm. dotk.name is the web app.
